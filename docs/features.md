# Feature Specifications

## Core Features (MVP)
1.  **Multiple Environments**: Support for distinct soundscapes (e.g., Forest, Beach, Urban, Underwater), each with a unique background image and color theme.
2.  **Sound Mixing Grid**: A responsive 3-column grid where users can toggle individual sounds on and off.
3.  **Independent Volume Control**: When a sound is active, a volume slider allows fine-tuning of that specific track.
4.  **Master Playback Controls**:
    - Global Play/Pause button to quickly mute/resume the entire mix.
    - Master volume control (optional for MVP, but desirable).
5.  **Sleep Timer**: Allow users to set a timer for the audio to fade out and stop automatically.
6.  **Responsive Design**: The UI must adapt gracefully from mobile screens to desktop browsers, maintaining the immersive feel.

## Future Enhancements
- **User Presets**: Save custom mixes (e.g., 'My Sleep Mix').
- **Offline Support (PWA)**: Allow the app to work without an internet connection once assets are cached.
- **Fade Transitions**: Smooth audio fade-in/fade-out when toggling sounds or switching environments.
- **Binaural Beats/Isochronic Tones**: Specialized audio categories.
