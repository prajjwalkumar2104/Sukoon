# Tech Stack

## Frontend Framework
- **Next.js (React)**: Chosen for its robust routing, performance optimizations, and scalability if backend features are added later.

## Styling
- **Tailwind CSS**: Enables rapid, utility-first styling, making it easy to replicate the specific colors, spacing, and responsive behaviors of the reference design.

## Icons
- **Lucide React** (or Phosphor Icons): Provides the clean, thin, stroke-based SVG icons essential for the minimalist aesthetic.

## Audio Engine
- **Howler.js**: The standard for web audio. It handles cross-browser inconsistencies, looping (critical for ambient sounds), and spatial audio effectively.

## State Management
- **React Hooks (useState, useContext)**: Sufficient for the initial MVP to manage active sounds, volumes, and current environments.

## Deployment (Planned)
- **Vercel**: Seamless integration with Next.js for hosting the web application.
